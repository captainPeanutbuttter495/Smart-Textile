# Sessions

A dated log of work sessions on the Smart Clothing App: what changed, what was decided and why, and what is still open.

---

## How this works

- Run `/session-log` in Claude Code at the end of a session (or write the note by hand from `_Templates/Session_Template.md`).
- One note per session: `Session_YYYY-MM-DD_Short_Slug.md`, where the slug is two to four PascalCase words naming the work. File names must be unique across the vault.
- A session note records **what happened on a day**. Domain notes (`Project/`, `Frontend/`, `Backend/`, `Infrastructure/`, `SystemDesign/`) record **what is true now**. If a session makes a domain note wrong, fix the domain note too and list it under **Notes Updated**.
- Add a row to the index below, oldest first.
